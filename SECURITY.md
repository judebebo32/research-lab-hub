# Security Policy

If you find a security vulnerability — for example a way to see another lab member's private data, bypass protocol review, or access the tenure record without permission — please report it privately to **judebebo32@gmail.com** rather than opening a public issue.

Include what you found, how to reproduce it, and its possible impact. You'll receive an acknowledgement, and fixes will be released as quickly as practical. Please give us reasonable time to fix the issue before disclosing it publicly.
